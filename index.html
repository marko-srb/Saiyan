Saiyan project

This project is a month long effort. Two-part project that brings generative art and motion-supported editing to WordPress. The project consists of a "Generative Art Engine" that produces animated code and vector content, and a "Motion-Supported WP Editor" that treats animated formats as first-class content. The goal is to create a seamless flow from content creation to publication.

Authors: Marko Ivanović & Nebojša Jurcić

Initiative: Automattic's Radical Speed Month
